# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, and Power BI. The objective was to transform raw data into meaningful business insights through data cleaning, exploratory data analysis (EDA), SQL querying, interactive dashboards, and reporting.

The project follows a real-world analytics process, starting with data preparation and ending with business recommendations presented through a dashboard and presentation.

---

## Project Objectives

* Load and explore the dataset using Python.
* Clean and prepare the data for analysis.
* Perform Exploratory Data Analysis (EDA) to identify trends, patterns, and anomalies.
* Store and query the data using SQL databases (PostgreSQL, MySQL, and SQL Server).
* Build an interactive Power BI dashboard.
* Create a business report summarizing key findings.
* Present insights using a professional Gamma presentation.

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python using Pandas.
* Examined the data structure, data types, and dimensions.

### 2. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data formats.
* Converted data types where necessary.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

* Generated descriptive statistics.
* Explored customer, product, and sales trends.
* Identified outliers and data distributions.
* Created visualizations to understand business performance.

### 4. SQL Analysis

The cleaned dataset was imported into relational databases to perform SQL analysis.

SQL tasks included:

* Filtering records
* Aggregations
* GROUP BY operations
* JOIN queries
* Window functions
* Ranking
* Business KPI calculations

The queries were executed using:

* PostgreSQL
* MySQL
* Microsoft SQL Server

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Data-Analytics-Project.git
```

### 2. Install Python libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 3. Open the Jupyter Notebook

```bash
jupyter notebook
```

Run the notebook to perform data loading, cleaning, and exploratory data analysis.

### 4. SQL Analysis

Import the cleaned dataset into:

* PostgreSQL
* MySQL
* Microsoft SQL Server

Execute the SQL scripts located in the **SQL** folder.

### 5. Power BI

Open the `.pbix` file using Power BI Desktop to explore the interactive dashboard.
